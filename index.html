JSON-to-Something

Free browser-based developer tool for converting JSON objects to TypeScript types, Zod schemas, and JSON Schema, plus converting YAML to Nginx and Envoy configuration.

JSON converters

Paste a JSON object to generate TypeScript interfaces, Zod validation schemas, and JSON Schema. Options include nullable field handling and string literal inference.

YAML config converters

Paste YAML service definitions to generate practical Nginx upstream and Envoy route configuration directly in the browser.

Private client-side processing

Conversion runs locally in the browser. JSON, YAML, generated output, history, and share data are not uploaded to a server.
